# Rambla Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, native macOS scrolling window manager ("Rambla") with feature parity to ChainYourMac 2.3 that coexists with Rectangle, idles at 0 % CPU and installs from a DMG.

**Architecture:** A Swift package with two targets. `RamblaCore` is a pure, unit-tested library: model, layout, strip operations, preferences, shortcuts, state. `Rambla` is an AppKit `LSUIElement` app. It runs one AX worker thread per managed app, a main-thread `WindowManager` that owns the model and applies layouts, and overlays and settings in AppKit/SwiftUI. Private SkyLight/CGS symbols are loaded with `dlsym`.

**Tech Stack:** Swift 6.3 toolchain (language mode 5), SwiftPM, Command Line Tools only (no Xcode), Swift Testing, AppKit, SwiftUI, Carbon hot keys, ApplicationServices (AX), CoreGraphics event taps, ServiceManagement. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-10-21-scroll-design.md` (Spanish). Executors read both documents.

## Global Constraints

- Platform: macOS 14.0+ (`LSMinimumSystemVersion` 14.0), arm64 only. Build with `swift build -c release`; never require Xcode or `xcodebuild`.
- No third-party packages. Only Apple frameworks.
- `Package.swift`: `swift-tools-version: 6.0`, `swiftLanguageModes: [.v5]`.
- Bundle id `io.github.coru29.Rambla`, app name `Rambla`, URL scheme `rambla`, CLI command `rambla`, signing identity name `Rambla Local Signing`.
- All model geometry uses global AX coordinates (origin at the top-left of the primary display, y grows downward). Convert to Cocoa only inside overlay code.
- UI copy is Spanish (Rioplatense neutral: "Configuración", "Atajos", "Pantallas"...). Identifiers and code comments are English.
- Zero CPU when idle: no repeating timers or polling, except (a) the 60 Hz animation timer while an animation runs, (b) the 3 s accessibility-permission check while permission is missing, and (c) the 10 Hz modifier check while the indicator is visible.
- Default modifier for shortcuts is ⌃⌘ (⌃⌘⇧ for "move" variants). Never ship a default that uses ⌃⌥ without ⌘ (Rectangle's space).
- Do not create git commits (the user has not asked for git). The "Commit" step of each task becomes "Run the full test suite / build and confirm green".
- Fresh frame tolerance: two frames are "the same" if every edge differs by ≤ 2 pt.

## Review Focus

1. **Windows lost off-screen** (quit, crash, pause, display unplugged): parked frames must always leave exactly `sliver` pt inside the owning display, and quit/pause must gather windows. Tests: Task 3 `parkingKeepsSliverInsideDisplay`; Task 6 live check `gather`.
2. **Rectangle moves a strip window**: the window must stay where Rectangle put it and become floating, never snap back. Tests: Task 9 live check `externalMoveFloats`.
3. **App enforces a minimum width larger than the column**: the layout must use the real width for following columns, without oscillating. Tests: Task 3 `minWidthPushesNeighbors`; Task 6 bounded re-layout (max 2 passes).
4. **Second display beside the laptop**: no parked or peeking window may put more than half of itself, or any parked part, on another display. Tests: Task 3 `parkingAvoidsNeighborDisplay`, `peekLimitedToHalfTowardNeighbor`.
5. **Shortcut collides with Rectangle or the system**: the defaults must not collide with either Rectangle default set when it is the active one (the "alternate" set), and registration failures must surface. Tests: Task 4 `defaultsDoNotCollideWithRectangleAlternate`; Task 8 live check that failures are listed.

```swift
import Foundation
import CoreGraphics

public typealias WindowID = UInt32

public enum HDirection: String, Codable, Sendable { case left, right }
public enum VDirection: String, Codable, Sendable { case up, down }
public enum PinSide: String, Codable, Sendable { case left, right }
public enum ColumnMode: String, Codable, Sendable { case stacked, tabbed }
public enum CenterMode: String, Codable, CaseIterable, Sendable { case never, onOverflow, always }
public enum InsertPosition: String, Codable, CaseIterable, Sendable { case afterFocused, start, end }

public enum ColumnWidth: Codable, Equatable, Sendable {
    case fraction(Double)
    case points(Double)
    /// A fraction f occupies f*(available+gap)-gap, so N columns of 1/N plus gaps fill `available` exactly.
    public func resolve(available: Double, gap: Double) -> Double {
        switch self {
        case .fraction(let f): return max(1, f * (available + gap) - gap)
        case .points(let p): return max(1, p)
        }
    }
    public func asFraction(available: Double, gap: Double) -> Double {
        switch self {
        case .fraction(let f): return f
        case .points(let p): return (p + gap) / (available + gap)
        }
    }
}

public struct Column: Codable, Equatable, Identifiable, Sendable {
    public var id: UUID
    public var windows: [WindowID]
    public var heightWeights: [Double]      // parallel to `windows`
    public var active: Int                  // index into `windows`
    public var mode: ColumnMode
    public var width: ColumnWidth
    public var widthBeforeFull: ColumnWidth?
    public var heightFraction: Double?      // single-window height (nil = full / original)
    public var pinned: PinSide?
    public init(id: UUID = UUID(), windows: [WindowID], width: ColumnWidth, mode: ColumnMode = .stacked) {
        self.id = id; self.windows = windows
        self.heightWeights = Array(repeating: 1, count: windows.count)
        self.active = 0; self.mode = mode; self.width = width
    }
    public var activeWindow: WindowID? { windows.indices.contains(active) ? windows[active] : windows.first }
}

public struct Strip: Codable, Equatable, Sendable {
    public var columns: [Column]
    public var focused: Int?                // index into `columns`
    public var scroll: Double               // strip-space x shown at the scroll area's left edge
    public init(columns: [Column] = [], focused: Int? = nil, scroll: Double = 0) {
        self.columns = columns; self.focused = focused; self.scroll = scroll
    }
}
```

  - `mutating func moveColumn(from: Int, to: Int)`: `to` is the final index; focus follows the moved column
  - `mutating func moveRow(_: VDirection)`: swaps the active window with its neighbor inside the column (weights travel with it); `active` follows

  - `mutating func popOut(_: HDirection)`: only when the focused column has more than one window. Removes the active window and creates a new column with the source column's width immediately left or right of the source. Focus goes to the new column.
  - `mutating func toggleTabbed()`
  - `mutating func togglePin(_: PinSide)`: if the focused column is pinned on that side, it is unpinned. Otherwise any other column pinned on that side is unpinned and the focused column is pinned there (switching side if it was pinned on the other one).
  - `mutating func cycleWidth(presets: [Double], available: Double, gap: Double)`: the current width becomes the first preset greater than `asFraction + 0.01`; if there is none, it wraps to `presets[0]`. Clears `widthBeforeFull`.
  - `mutating func toggleFullWidth()`: the width becomes `.fraction(1)` and the previous one is saved in `widthBeforeFull`; if `widthBeforeFull` is set, it is restored and cleared
  - `mutating func adjustWidth(by delta: Double, available: Double, gap: Double)`: new fraction = clamp(`asFraction + delta`, 0.1, 1.0)
  - `mutating func adjustHeight(by delta: Double, hidden: Set<WindowID>)`:

  - `mutating func setHeightShare(window: WindowID, share: Double, hidden: Set<WindowID>)`: same rescale with an explicit target share, clamped to 0.1…0.9
  - `mutating func equalizeHeights()`: all weights become 1 and `heightFraction = nil`
  - `mutating func setWidth(points: Double, window: WindowID)`

Rules the tests pin down:
- **Rambla area**: `viewport` minus the pinned columns.
  - A left-pinned column (if not collapsed) takes width `wL = width.resolve(available: viewport.width, gap:)` at `viewport.minX`, so the area starts at `minX + wL + gap`. The right one is symmetric.
  - Unpinned widths resolve against `area.width`.
- **Metrics**:
  - For laid-out columns (unpinned, not collapsed), the width is `max(resolve, max minSizes[w].width over visible windows)`, with `xs[0] = 0` and `xs[i+1] = xs[i] + w_i + gap`.
  - Pinned and collapsed columns get width 0 and the xs of the next slot, without consuming a gap.
  - `total` = right edge of the last laid-out column (0 if there are none).
- **Screen x** of column i = `area.minX + xs[i] - strip.scroll`. The y range is `area.minY…area.maxY`.
- **Stacked**: the visible windows (not hidden) split the height `area.height - gap*(k-1)` by `heightWeights`, top to bottom.
  - A single visible window uses `heightFraction*area.height` when set. Otherwise, with `keepOriginalHeight` and `originalHeights[w]` available, it uses `min(original, area.height)`. Otherwise the full height. Always top-aligned.
- **Tabbed**: every visible window gets `(x, area.minY + tabBarHeight, w, area.height - tabBarHeight)`, and `tabBars[col.id] = (x, area.minY, w, tabBarHeight)` unless the column is parked.
- **Visibility** with display `D`:
  - A column is **parked right** if `x >= D.maxX - 1`, and parked left if `x + w <= D.minX + 1`.
  - Toward a side where the part beyond `D` intersects some other display, it is also parked if more than half of `w` lies beyond the edge.
  - Otherwise it is `.visible` at its real frame, and may extend beyond the screen edge.
- **parkingFrame** keeps `frame.size`. Candidates in order (bottom corners were dropped after a live test showed macOS clamps y):
  1. edge of `side`: x = `D.maxX - sliver` (right) or `D.minX + sliver - w` (left), y = `frame.minY`
  2. the opposite side's edge

  It returns the first candidate that does not intersect any rect in `others` (zero-area touching does not count as intersecting), and candidate 1 if none fits.
- **reveal** (w = `m.area.width`, xi/wi of the column):
  - `.never`: if `wi >= w`, then `xi`; else if `xi < current`, then `xi`; else if `xi + wi > current + w`, then `xi + wi - w`; else `current`. Then clamp to `[0, max(0, total - w)]`.

### Task 13: Trackpad gesture and mouse focus

- Modify: `Engine/WindowManager.swift`

**Interfaces:**
- Produces:

    - `init(onBegin: @escaping () -> Void, onChange: @escaping (_ dx: Double) -> Void, onEnd: @escaping () -> Void)`
    - `func configure(enabled: Bool, fingers: Int)`

    It uses a listen-only `CGEventTap` (`cgSessionEventTap`, mask `1 << 29`). Each event is turned into `NSEvent(cgEvent:)` and its `allTouches()` are read.
